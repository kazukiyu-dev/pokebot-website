# PokeBot Website

A complete static website for PokeBot, built from the supplied bot project.

## Included pages

- `index.html` — landing page and feature overview
- `guide.html` — complete player and server-owner guide
- `commands.html` — searchable directory generated from the bot's 111 slash commands
- `privacy.html` — privacy policy template
- `terms.html` — terms of service template

## Preview locally

You can open `index.html` directly, or run a simple local server from this folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish for free

### GitHub Pages

1. Create a new GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Open **Settings → Pages**.
4. Set the source to **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub to provide the public URL.

### Netlify

1. Sign in to Netlify.
2. Choose **Add new site → Deploy manually**.
3. Drag this entire folder into the upload area.
4. Netlify will publish the site and provide a public address.

### Cloudflare Pages

1. Create a Pages project.
2. Connect a Git repository containing this folder.
3. Use no build command and set the output directory to `/`.
4. Deploy.

## Updating commands

The command directory data is stored in `assets/js/commands-data.js`. It was generated by reading the slash-command decorators in the supplied bot project. Regenerate or edit that file after adding or removing commands.

## Important review before publishing

Review the privacy policy and terms so they accurately match how the hosted production bot is operated, where data is hosted, how long it is retained, and who users should contact. The current pages are practical templates based on the supplied source code, not legal advice.
